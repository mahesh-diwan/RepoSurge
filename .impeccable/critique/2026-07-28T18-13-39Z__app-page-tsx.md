## RepoSurge Design Critique

**Method:** dual-agent (A: design review · B: CLI detector + browser)

---

### Anti-Patterns Verdict

**Partial AI slop.** The list is clean — single column, no card grid, no glassmorphism, no gradient text, no side-stripe borders, no numbered sections. But the hero is pure AI template: oversized `text-8xl` centered title + paragraph + generous padding. First-time visitors scroll past 450px of brand to find the actual product.

**Detector:** 0 findings — clean markup.
**Browser:** 0 console errors. 25 repos with descriptions + sparklines + rank changes all rendering. Skip link, ARIA landmarks, search input, sticky column headers all working.

---

### What's Working

1. **Single-column list** — avoids card-grid fatigue. Rank immediately scannable.
2. **RankChange + sparkline + description trio** — trajectory, momentum direction, and repo purpose in ~100px.
3. **Semantic color system** — amber for surge, green positive, red negative. Consistent with velocity dashboards.

---

### Priority Issues

**P0 — No error/loading/empty states.** getRepos could fail silently. No skeleton, error banner, or fallback.

**P0 — Hardcoded period.** getRepos("week") in page.tsx. No inline period toggle.

**P1 — Hero overshadows data.** 32pt top + 20pt bottom + 8xl heading on a ranking dashboard. Compress or move to nav.

**P1 — No interactive controls.** Sort by columns is it. No language/min-stars filter, no period toggle.

**P2 — z-index pollution.** Three separate z-[2] declarations. One tweak breaks stacking order.

**P2 — RankChange always positive.** Every repo shows ↑N. Reads as noise, not signal.

---

### Persona Red Flags

**Alex (Power User):** No keyboard shortcuts beyond ⌘K. No bulk actions. No language filter. No density toggle. Must navigate between /daily /weekly /monthly pages.

**Sam (Accessibility-Dependent):** Sparkline SVGs lack role="img" + aria-label. RankChange conveyed via arrow + color only — no text alternative. text-muted #888888 on #0A0A0A = 5.4:1. Skip link targets above hero, not data list.

---

### Minor Observations

- "RS" nav logo cryptic. Use full word or add symbol.
- Pt-32 pb-20 hero wastes 250+ vertical pixels before data.
- z-[2] appears 3 times across files. Maintenance risk.

---

### Questions to Consider

1. If you deleted `<Header />`, would any user notice?
2. When every repo shows ↑N, rankChange stops conveying information. Different baseline?
3. Period selector as dropdown inline vs separate route pages?
4. Does sparkline earn its render cost for 25 identical upward slopes?
