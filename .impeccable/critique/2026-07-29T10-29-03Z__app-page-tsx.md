**Alex (Power User)**: Full keyboard flow — `/` search, `↑↓` navigate, `Enter` detail, `Escape` close, `?` shortcuts, `⌘C` copy, `⌘K` search. Grid/list toggle for density preference. Column visibility for customized view. Toast with undo for filter resets.

**Sam (A11y)**: All interactive elements focusable. Skip-to-content link. Semantic HTML (banner, nav, main, dialog). Tooltips supplement visual labels. Toast uses `aria-live="polite"`. LoadingSkeleton uses `aria-busy="true"`. ShortcutsModal has focus trap + `aria-modal`. Color contrast ≥3:1.

**Riley (Edge Cases)**: Empty periods handled. Error boundary catches crashes with retry. Search with 500 chars handled. Synced data never flashes loading state (sync access). Min-stars clamps invalid values.
